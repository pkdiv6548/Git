Everything around your code, in context.

The roadmap brings version control, collaboration and release workflows into one focused workspace. This is a frontend prototype; backend features are not live yet.

⑂ Repositories & branches

Organize source code, inspect file history, compare branches and track changes.

  • Public/private repository model
  • Branches, tags and commit history
  • README and source viewer
  • Diffs and protected branches

✓ Issues & reviews

Give work a clear owner and make code review part of everyday development.

  • Issues, labels and milestones
  • Pull requests and reviews
  • Merge state and history
  • Team permissions

⌁ Automation

Build toward repeatable checks, safe deployments and reliable releases.

  • Workflow definitions
  • Build artifacts
  • Deployment status
  • Signed webhooks

⌕ Search

Find relevant projects while respecting repository access rules.

  • Repository and topic search
  • Language and owner filters
  • Permission-aware results
  • Pagination and sorting

♙ Teams & identity

Build a clear access model for users, organizations and teams.

  • Profiles and activity
  • Organization membership
  • Role-based permissions
  • Secure sessions and audit events

◇ Security & reliability

Make safety, recoverability and system health requirements from the start.

  • Rate limits and secret handling
  • Backups and restore tests
  • Monitoring and audit logs
  • Accessibility and responsive UI
Current status: frontend prototype. Real Git transport, authentication, persistence, pull requests, billing and CI/CD need backend implementation and end-to-end testing.
